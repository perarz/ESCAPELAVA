## Round flow — 18.10.2026

GameLoop now owns LOBBY → PREPARING → COUNTDOWN → ROUND → FINISHING → RESETTING → POST_ROUND. PREPARING invokes registered PlayerService round preparer synchronously; spawns/teleports and root locks finish before 1.7s settling and 3s countdown. ROUND releases recorded root anchored states and starts lava. PlayerService.isAlive now means an alive participant in ROUND (items, cash, anti-cheat inactive during preparation/finish); getAliveList still snapshots participants for rewards. FINISHING freezes lava growth without resetting it, snapshots rewards through RoundFinished, holds 3s. RESETTING gives curtain 0.6s before existing RoundEnded cleanup and POST_ROUND/lobby/reset. Existing 2s death respawn retained. Remote GameStateChanged adds endsAtServerTime as third argument; countdown uses Workspace:GetServerTimeNow. Abort returns to LOBBY and releases locks. RoundTransition cancels old flows, preloads digit assets and uses bounded cover during spawn, then hides cleanup and unveils lobby after 1.2s. Source/UI installer and validation harness: artifacts/round-flow-v1.
